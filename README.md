# ELSEWHERE v0.2.2 — Discovered messages

Changes: No world headings, instructional captions, or status footers. Topography's identity prompt materializes at its fixed discovery point in a compact capsule; the name field and submit button are capsules. The original React Bits Topography remains in use with color #240775.

## Updating an existing v0.2.1 project
Copy `src/App.jsx`, `src/style.css`, and `scripts/install-topography.mjs` from this archive into your existing project. Keep your already installed `src/reactbits/Topography.jsx` and `Topography.css`. No reinstall required.

## Fresh install
`npm.cmd install`
`npm.cmd run setup:topography`
`npm.cmd run dev`

The installer now adds the React import required by the current Vite setup. React Bits source is downloaded at setup time; the archive does not contain that source.
